# Tender Management System Backend

This is the backend service for the Tender Management System, built with FastAPI.

## Installation

```bash
pip install -e .
```

## Running the server

```bash
uvicorn app.main:app --reload
```

## API Documentation

Once the server is running, you can access:
- API documentation at: http://localhost:8000/docs
- OpenAPI specification at: http://localhost:8000/openapi.json
